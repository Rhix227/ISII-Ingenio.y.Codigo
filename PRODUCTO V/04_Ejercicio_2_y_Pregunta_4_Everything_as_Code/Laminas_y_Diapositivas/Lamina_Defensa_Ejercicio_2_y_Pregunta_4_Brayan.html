⚠️ 1. Deriva de Configuración
El Síndrome Local
«En mi máquina sí funciona»: Entornos heterogéneos y dependencias globales no controladas.
Snowflake Servers
Servidores de producción con scripts Bash manuales, imperativos y no versionados.
Impacto en Calidad
Configuration Drift: Desfase invisible que causa caídas catastróficas en producción y alto MTTR.
🐳 2. Solución: Dockerfile
# 1. Imagen inmutable fija
FROM node:20.17.0-alpine3.20
WORKDIR /usr/src/app
# 2. Caché de capas
COPY package*.json ./
RUN npm ci --only=production
# 3. Seguridad: Usuario no root
COPY --chown=node:node . .
USER node
EXPOSE 8080
CMD ["node", "server.js"]
Paridad Dev/Prod
El contenedor sella runtime, SO y código en un hash inmutable SHA-256.
🏛️ 3. Evolución de SCM
SCM Clásica (Ayer)
Plan de Configuración en Word: Documento estático, desactualizado y burocrático.
SCM Moderna (Hoy)
Everything as Code: Manifiestos ejecutables y versionados directamente en Git.
Auditoría Total
Trazabilidad criptográfica de cada cambio mediante commits y Pull Requests aprobados.

compose.yml Reproducibilidad de la arquitectura de red multicapa.
